# Mobile Appointment Booking App UI/UX Design

## Project Overview
This project is a mobile-first appointment booking app designed for a luxury beauty salon.

The app helps users browse services, choose stylists, select appointment times, and confirm bookings through a seamless mobile experience.

---

## Problem Statement
Many salons still manage appointments through:
- WhatsApp messages
- phone calls
- manual scheduling

This often leads to:
- missed bookings
- scheduling confusion
- delayed responses
- poor customer experience

---

## Solution
I designed a clean and intuitive mobile booking experience that simplifies the appointment process and improves usability for both customers and salon staff.

---

## Features
- User onboarding flow
- Login / Sign Up
- Service selection
- Stylist selection
- Date & time booking
- Booking confirmation
- Mobile-first navigation

---

## UX Goals
- Reduce booking friction
- Improve accessibility
- Create a smooth booking flow
- Build trust through premium visuals

---

## Design Style
The app follows a dark luxury aesthetic using:
- Deep maroon tones
- Pink accent highlights
- Rounded cards
- High-contrast UI elements
